# Documented APRS vectors

These 18 JSONL files retain all 1,538 individual packets and 23 sequence
occurrences from [edition 1](../../docs/APRS_COMPLIANCE_VECTORS.md): 1,561 rows and
1,545 original case IDs. Every raw TNC2 byte, source expectation, receiver option
and provenance field is unchanged from PR #4. A frozen integrity test protects
that requirement, independently of regeneration.

Run from the repository root:

```sh
python -m pytest packages/aprs/tests -q
python packages/aprs/tests/generate_vectors.py
```

The generator translates source assertions, never parser output. The translated
expectations are stored in these JSONL files; comparisons do not convert them
back to the source schema. Schema changes include units/enums, explicit absence,
telemetry channel padding, structured query responses and typed NMEA sentences.
`packet` is a Latin-1 byte carrier:
use `packet.encode("latin-1")`, including for control/high-bit bytes.

`expected` is a subset of the public JSON representation. Missing keys make no
assertion; explicit nulls do. `source_expected` preserves the original assertions.
`unmapped` means outside the JSON projection, **not untested**: `source_details.py`
checks every such path using models, evidence, derived properties or the private
historical receiver adapter. It also checks FAP's flattened NMEA observations.
Rejection cases also check retained headers and partial observations, including
invalid timestamps and the historical receiver's validation order. Error wording
is represented by the public diagnostic scheme rather than copied verbatim.

Some profiles conflict for the same bytes. `_compatibility.py` expresses those
receiver policies without changing the public API or consulting expected values.
The canonical codec retains precise wire data; the adapter selects historical
comment trimming, disputed wind-unit interpretation, acceptance and warning policies.

The schema migration rewrote 35 stored expectations (33 FAP and two historical
position cases): equivalent weather units, compressed weather wind nesting,
`LegacyPosition`/`RawWeather` wrappers, four flattened NMEA observations, and four Mic-E device markers split from comments.
Captured rounded values, whitespace, absent symbols, and incomplete reports were
not changed to agree with the decoder. For example, FAP-357 still expects course
28 despite the wire containing 27.9. Uncompressed FAP wind retains an explicit
mph interpretation rather than changing to the public decoder's disputed unit.

Nineteen formerly adapter-dependent cases now compare public packet JSON directly,
with regression tests disabling the compatibility view. Offline conversion tests
reverse unit changes back to the captured measurements and verify stored fields
against source values. The original `source_expected` snapshots remain immutable
provenance; their supplemental observations without public model fields remain
explicitly asserted, not discarded or silently added to the packet schema.

All 29 PHG/PHGR projections (including 15 FAP vectors) instead exercise the public
API directly. Regression tests disable compatibility functions while checking
them. Their comment separators, whitespace, and numeric/alphabetic rates are
handled by the public codec. FAP's legacy-position wrapper and omitted trailing
telemetry channels are expressed using the existing JSON schema; original source
values remain unchanged and are also checked.

Sequence rows contain `state_expected` and run all preceding steps through a test
receiver implemented using public packet models. State is not added to the codec.

All 1,561 rows pass without xfails. Every row also participates in encoding tests:
1,296 semantic round trips under an explicit permissive envelope policy
(`EnvelopePolicy(".*", ".*", ".*")`), with checksum repair for three intentionally bad NMEA
checksums, and 265 explicit malformed/conformance refusals. The reviewed
`../roundtrip_exceptions.json` records exact reasons. Adding a new unexpected
refusal or silently fixing a recorded one fails the test; this file is not
regenerated by `generate_vectors.py`.

The new default `APRS_IS` policy additionally refuses serialization for 13 of
those round-trippable packets because of their address formats. The tests assert
those refusals separately and validate the other 1,283 under the default policy.
This preserves the source vectors while exercising both representation and
transport constraints through the public API.

Round-trip tests remove all evidence fields before serialization, check semantic
fields at wire precision, and require canonical bytes to stabilize. Raw wrappers
retain `information` because it is their semantic content. JSON round trips are
also checked for every input, including `Malformed` results.

Tests and fixtures are repository resources, not runtime package data. The CI
workflow tests source and a freshly installed wheel. Pinned FAP provenance and
licensing attribution remain in the unchanged source document.
